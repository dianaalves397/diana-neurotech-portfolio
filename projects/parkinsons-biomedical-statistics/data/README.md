# Data provenance

## Official source

**Oxford Parkinson's Disease Telemonitoring Dataset**  
UCI Machine Learning Repository  
Dataset DOI: `10.24432/C5ZS3N`  
Licence: **CC BY 4.0**

Official dataset page:
`https://archive.ics.uci.edu/dataset/189/parkinson`

The dataset contains 5,875 repeated voice recordings from 42 people with early-stage Parkinson's disease collected during an approximately six-month telemonitoring study.

Important fields include:

- `subject#` — participant identifier;
- `age` — participant age;
- `sex` — participant sex coding supplied by the dataset;
- `test_time` — time since recruitment;
- `motor_UPDRS` — clinician motor UPDRS score, linearly interpolated;
- `total_UPDRS` — clinician total UPDRS score, linearly interpolated;
- jitter measures;
- shimmer measures;
- `NHR`, `HNR`;
- `RPDE`;
- `DFA`;
- `PPE`.

## Folder policy

```text
data/
├── raw/        # untouched source file
└── processed/  # generated by R scripts only
```

Never edit the raw dataset manually.

Expected raw filename:

```text
data/raw/parkinsons_updrs.data
```

The processed file should be created by `R/02_cleaning.R` and must be reproducible from the raw file.

## Citation

When publishing results, cite the UCI dataset and the associated telemonitoring paper listed on the UCI record.

## Privacy

The public UCI dataset uses participant identifiers rather than names. Do not attempt to identify participants or combine the data with external information for re-identification.
