# Results

Generated analysis outputs belong here.

```text
results/
├── figures/  # plots used in README/report
├── tables/   # CSV/TSV/HTML statistical tables
└── models/   # serialized models or model summaries
```

Do not place manually edited results here. Every public result should be reproducible from the R scripts and source data.

Recommended final public outputs:
- participant characteristics table;
- outcome/trajectory figure;
- selected association figure;
- mixed-effects coefficient table/forest plot;
- diagnostic summary.
