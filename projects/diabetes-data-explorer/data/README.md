# Data

Place the coursework CSV at:

```text
data/diabetes.csv
```

Expected columns:

```text
gender
age
hypertension
heart_disease
smoking_history
bmi
HbA1c_level
blood_glucose_level
diabetes
```

The coursework file used for the published results contains 18,500 rows.

Reference dataset with the same schema: [Diabetes Prediction Dataset — Kaggle](https://www.kaggle.com/datasets/iammustafatz/diabetes-prediction-dataset).
