# Figures

Use this folder for portfolio-ready visual evidence produced during the project.

Good examples:

- system architecture diagram;
- risk-management workflow diagram;
- traceability map;
- example gait signal / input data plot;
- gait-metric result plot;
- verification summary chart;
- screenshots of the final interface.

Use descriptive filenames such as `architecture-v1.svg`, `risk-flow.svg`, `gait-metrics-example.png` and `verification-summary.svg`.
